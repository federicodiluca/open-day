# Open Day - Sfide di Informatica

Mini-giochi per gli open day dell'indirizzo Informatica (ISISS Gobetti-De Gasperi).

**Online:** https://open-day.federicodiluca.com

## Contenuto

- `index.html`: 5 sfide a tab (circuiti, porte logiche, binario, robot, CSS), con livelli e stelle.
- `carta-identita.html`: pagina HTML semplice da personalizzare nell'editor.

Pagine statiche, nessuna dipendenza, adatte anche a smartphone: funzionano offline con un doppio clic.

## Uso in laboratorio

- Copiare i file in locale su ogni PC.
- "Nuovo giocatore" (doppio clic) azzera i progressi per il gruppo successivo.
- I pallini accanto al titolo del livello permettono di saltare a un livello qualsiasi.
